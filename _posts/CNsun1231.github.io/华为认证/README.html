ARP协议---地址解析协议
48位二进制全1--12位全F---广播地址
ARP缓存表老化时间180S
ARP的工作原理：ARP发送广播报文进行请求，所有收到广播报文的设备都会先将IP地址和源
MAC地址的对应关系记录在ARP缓存表中，再看请求的IP地址，如果不是本地的IP地址，则直接
丢弃数据包，如果是本地的IP地址，则将回复ARP应答报文，之后再数据的传输中，优先查看
ARP缓存表，如果表中存在记录，转发，若没有则再次发送ARP报文。

ARP欺骗

ARP分三类
正向ARP---通过IP---MAC
反向ARP---mac---IP 
免费ARP

2.检测地址冲突
