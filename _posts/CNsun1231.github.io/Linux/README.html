Linux 学习笔记

这里记录 Linux 操作系统相关的学习内容，包括命令、运维、配置等。

一.理解操作系统中的名词

1.什么是Linux

Linux是一种内核（kernel），负责对于系统软件运行的调度，相当于人的大脑，只有内核可以直接调度
硬件
内核是操作系统最基本的部分。它是为众多应用程序提供对计算机硬件的安全访问的一部分软件，这种
访问是有限的，并且内核决定一个程序在什么时候对某部分硬件操作多长时间

2.什么是shell

内核的保护机制，负责对软件请求进行分析处理和屏蔽，同时提供一个和操作者沟通的交互界面

3.如何在shell中输入命令

（1）命令必须在提示符之后输入否则无法运行
